# Aurah · 发布仓库

这里存放 **Aurah 桌面音乐播放器** 的正式安装包与更新清单（`latest.yml`）。
源码仓库：https://github.com/c855pw2jkl-source/echomusic-gai

## 下载

到 [Releases](https://github.com/xzh67/aurah-releases/releases) 下载最新版本的 `Aurah-<版本>-Windows-Setup-x64.exe`。

国内下载慢时，可用 [ghfast.top](https://ghfast.top) 加速：把下载链接粘贴进去即可。

## 安装

1. 双击安装包，按向导完成安装
2. 从开始菜单或桌面快捷方式启动
3. 首次启动确认用户协议

安装包未购买代码签名证书，Windows SmartScreen 可能提示「未知发布者」，
点击「更多信息 → 仍要运行」即可。

## 更新

已安装旧版本时，打开应用 → **设置 → 关于 → 检查更新**。
更新默认通过加速镜像下载，失败会自动回退直连 GitHub。

## 系统要求

- Windows 10 / 11 x64
- 约 300MB 磁盘空间

## 许可证

Aurah 以 **AGPL-3.0-only** 发布，包含来自 [folia-major](https://github.com/chthollyphile/folia-major)（AGPL-3.0）的歌词渲染代码。
